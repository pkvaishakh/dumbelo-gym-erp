# LiveSessionComplete

The sheet that ends a live session.

End Session stops the clock and opens it: a tick, "Session complete", one line saying the workout is logged and the pack updated, then exercises, sets, time and the sessions used in the member's training pack. Done returns to Trainer Home. Keep Going closes the sheet and restarts the clock.

- The sheet does not close on a tap outside it: the trainer has to choose Done or Keep Going.
- Ending a session uses one session from the pack. Say the new count here so the trainer can tell the member.
