# MembersListSearch

The Members list while searching, "ra" typed and three matches.

The list narrows as you type and the count line changes to "3 members found". A cross appears in the field to clear the text. The chips stay, so a search can be combined with a status. Load More is hidden: a search returns everything that matches.
