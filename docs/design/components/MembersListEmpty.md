# MembersListEmpty

The Members list when a search matches no one.

The list card is replaced by an EmptyState that repeats what was typed, says what to try, and offers Add Member and Clear Search. When filters, not a search, leave nothing to show, the title is "No members match these filters" and the only button is Clear Filters.
