# PerformanceChart

A compact chart card: a measure toggle, a period selector, a headline total with its change, and a 180px chart.

Use once on Admin Home. You provide, for each measure and period, the values, the headline total, the comparison text and the axis labels. Each combination is a `rl-perf__panel`; the script shows the one that matches the two SegmentedControls.

- 7D is bars, one per day, with today's bar in `volt` and its value on the cap. 30D and 3M are a 2px `ink` line with a `volt` end point and its value beside it.
- Each bar or point is a button: tap, hover or focus shows a tooltip with the exact value and the day. Tapping elsewhere clears it.
- Bar heights and point positions are set with `--v` (0 to 1 of the axis maximum) and `--x`. Round the axis maximum to a clean number and show three ticks.
- One series only. For a second measure, use the toggle, never a second axis.
