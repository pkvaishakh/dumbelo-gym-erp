# AccountDetails

Account Details: the signed-in person's own account.

A detail screen behind the More tab. Top to bottom: back arrow and title, the person's photo, name, role and branches, then four sections. Personal details (full name, mobile number, email) with an Edit link. Role and access (role, branches, account created), which cannot be edited here. Sign-in and security (Change Password with the date it was last changed, Signed-in Devices). Notifications, as four Switches. Sign Out and the app version close the screen.

You provide the account. The script in `preview.html` sends `rl:account-edit`, `rl:account-password` and `rl:sign-out` events and shows edited values when they come back.

- Every value has its label above it (DetailList).
- What the person may change has a control: an Edit link, a row with a chevron, a Switch. What they may not change is plain text with one line saying who can.
- A Switch takes effect at once; there is no Save button on this screen.
- Every role gets this screen, behind its own More tab, with its own access section, notifications and bottom navigation. See AccountDetailsReceptionist and AccountDetailsMember.
- Signed-in Devices opens SignedInDevices.
- The create button keeps working here: it opens the role's create sheet.
- Related: EditAccount, ChangePassword, AccountDetailsWide.
