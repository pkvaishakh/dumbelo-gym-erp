# MemberWorkoutComplete

The sheet that ends a workout.

Finish Workout stops the clock and opens it: a tick, "Workout complete", one warm line, then exercises, sets and time. Done returns to where the workout was started and shows that screen in its finished state. Keep Going closes the sheet and restarts the clock, for a tap made by mistake.

- State what was done, not what was planned: "5 of 6" if one exercise was skipped.
- No confetti, no badges, no exclamation marks.
