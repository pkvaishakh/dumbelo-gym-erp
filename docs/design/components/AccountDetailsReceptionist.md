# AccountDetailsReceptionist

Account Details for a receptionist.

The same screen as the Admin's, with the role's own content. Role and access shows one branch, not all four. Sign-in and security has Change Password only. Notifications are the ones a front desk needs: check-in alerts for a member with a payment due or an expiring plan, shift reminders, new members. The bottom navigation is the front desk's, with More current. Trainers get the same screen with their own notifications (session reminders, member check-ins, missed sessions).
