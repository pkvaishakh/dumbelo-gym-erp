# MemberWorkoutActive

A workout in progress: every exercise with its sets, ticked off as they are done.

A task screen, so it has a close button, a bar under the top bar and an action bar in place of the bottom navigation. The top bar counts sets ("8 of 18 sets") and the bar fills with them. Each exercise is a SetTracker card. The action bar shows the running time beside Finish Workout.

You provide the exercises and save each tick. The script in `preview.html` counts sets, marks an exercise done when all its sets are ticked, runs the clock, and opens the summary sheet.

- A set is ticked with one tap anywhere on its chip, and unticked the same way. No confirm.
- All exercises stay open; nothing collapses, so a member can do them in any order.
- Finish Workout is always enabled. Finishing early is allowed and the summary says what was done.
- Closing keeps the ticks; the member can come back to the same workout.
