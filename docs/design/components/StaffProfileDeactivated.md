# StaffProfileDeactivated

Staff Profile for a deactivated account.

The status badge reads "Deactivated" in `danger-soft`, the Account section says "Cannot sign in", and its only button is "Reactivate Account". Everything else stays readable, so the admin can still see who the person was and reach them.
